Add Plex server

Use a server origin, without paths or token query parameters. Redirects are refused. Private network and loopback servers are supported when reachable from Ordarr; link-local/metadata addresses are blocked.

HTTPS certificate checks stay enabled. Tokens are encrypted in SQLite using credentials.key in the persistent data directory. Back up the key with your database; losing it makes saved tokens unusable.
