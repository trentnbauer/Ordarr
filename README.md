# Ordarr

Self-hosted watch-order management for Plex, Jellyfin, and the *arr ecosystem.

Create, import, and sync collections containing movies and individual TV episodes in a custom playback order.

## Features

- Mix movies and TV episodes in any order.
- Import and share collections via files or URLs.
- Sync ordered playlists to Plex and Jellyfin.
- Automatically add newly downloaded media in the correct position.
- Identify missing media with Sonarr and Radarr integration.
- Docker deployment.
